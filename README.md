# 🚀 HackPrep AI
**You.com-powered hackathon project planner for solo students**

[![Live Demo](https://img.shields.io/badge/Live_Demo-Deploying-blue)](https://hackprep-ai.onrender.com)

## ✨ What it does
Input: "You.com APIs + Python solo student"  
Output: Project idea, tech stack, 48hr timeline, code snippets

## 🛠️ Tech Stack
Frontend: HTML/CSS/JS + Bootstrap
Backend: Python Flask + You.com API
Deployment: Render.com (free)

## 🚀 Quick Start
pip install flask requests
python app.py
